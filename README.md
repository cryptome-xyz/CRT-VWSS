# CRT-VWSS

This is a C++ prototype of verifiable weighted secret sharing scheme based on the Chinese Remainder Theorem (CRT). 

The implementation includes:
- CRT-based verifiable weighted secret sharing;
- integer commitments over an imaginary quadratic class group;
- Range proof using three-square decomposition (Couteau et al. 2021);


## Requirements
- A C++17 compiler
- CMake 3.16 or newer
- [NTL](https://libntl.org/)
- [PARI/GP](https://pari.math.u-bordeaux.fr/)
- [OpenSSL](https://www.openssl.org/)
- SageMath if regenerating the class-group parameters


## Build and run
To build and run benchmark: 

```bash
./makeRunTest.sh
```

## Select a benchmark vector

The active weight vector is selected in `src/benchmark.cpp`:

Select ETH weight vector: 
```cpp
VWSS::Params params = test_vector_eth();
```
 
Select randomly generated weight vector with different number of parties:

```cpp
VWSS::Params params = test_vector(4);
VWSS::Params params = test_vector(8);
VWSS::Params params = test_vector(16);
VWSS::Params params = test_vector(32);
VWSS::Params params = test_vector(64);
VWSS::Params params = test_vector(128);
```

The partition strategy is selected by the second argument to `setup_dealer_and_parties`:

```cpp
vwss.setup_dealer_and_parties(params, true);  // method 1
vwss.setup_dealer_and_parties(params, false); // method 2
```

- Method 1 puts every party with weight below `lambda` in set A, then adds high-weight parties until A reaches the reconstruction threshold.
- Method 2 adds the largest parties to A until it reaches the reconstruction threshold; consequently, set B may contain parties whose weights are below `lambda`.

## Class-group parameters

The benchmark uses a hard-coded 1600-bit negative discriminant and two class-group generators in `src/intcom.cpp`. They can be reproduced or regenerated with the included SageMath script:

```bash
sage src/class_group.py
```
